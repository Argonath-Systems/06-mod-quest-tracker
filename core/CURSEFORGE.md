# Quest Tracker UI

## Summary
HUD overlay displaying active quest objectives.

## Metadata
- **Class**: Mods
- **Main Category**: Cosmetic
- **Additional Categories**: Map and Information

## Description
Keep your goals in sight. A customizable HUD element that lists your tracked quests and their progress.

### Key Features
* **Feature Rich**: Built with extensibility and performance in mind.
* **Integrated**: Seamlessly works with other LordOfTheTales modules.
* **Configurable**: extensively configurable to suit your server's needs.

2. Place it in your server's `mods` or `plugins` folder.
