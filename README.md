# 06-mod-quest-tracker

Hytale modding component: mod-quest-tracker

## Installation

```xml
<dependency>
    <groupId>com.argonathsystems.mods</groupId>
    <artifactId>quest-tracker-ui</artifactId>
    <version>1.0.0-SNAPSHOT</version>
</dependency>
```

## Building

```bash
mvn clean install
```
